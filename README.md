# International Sign Language

Open source toolkit for sign language accessibility:

- **speech / text → sign language** with 3D signing avatars (hands, fingers, facial expressions);
- **sign language → text** from a camera or a video file;
- an **overlay** for TV, streaming (OBS, CasparCG) and websites;
- an **API and SDKs** for developers;
- **learning** and **model training** with community data.

Target languages first: ASL, BSL, LSF, DGS, LSE, Libras, PJM and International Sign.

> Status: planning. See [PLAN.md](PLAN.md) for the full development plan and [TODO.md](TODO.md) for the checklist.

The avatar adds to human interpreters; it does not replace them. Every sign carries a review status, and only signs checked by native Deaf signers are marked `verified`.
